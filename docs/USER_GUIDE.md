# User Guide

Open **https://ava.office.local** from an office computer, tablet or phone (or through
the Fortinet VPN) and sign in with your own account.

## Asking AVA
Type a question on the **AVA** page, or use the box on any project page — AVA then knows
which project you mean.

Examples that work today:
* "What requires attention today?" / "¿Qué tengo hoy?"
* "Find project 25006." or just "25006"
* "What deadlines are within the next 30 days?"
* "Who is the structural engineer on 25006?"
* "What are we waiting for on this project?" (from a project page)
* "Draft a follow-up email to the structural engineer about the revised drawings."
  → produces a **draft** only; nothing is sent.

How to read answers:
* **Sources** under each answer link to the records used. If there is no source, the
  answer is general, not office information.
* AVA says "not configured" or "not available yet" instead of guessing. Email, calendar,
  Dropbox documents, invoices, reports, RFIs and submittals arrive in later phases.
* If two sources disagree, AVA shows both — you decide which is right.

## Projects, clients, consultants
* **Projects**: filter by number, name, client or location; open a project for its
  dashboard; **Edit** to update phase, deadline, team, consultants, Dropbox folder.
  Projects are archived, never deleted.
* **Clients / Consultants**: firms with their contact people. Link consultants to a
  project by discipline in the project editor.

## Search
The top search bar finds projects, clients, consultants and people, tolerating accents
and small typos ("Juan Ramon" finds "Juan Ramón").

## Mobile
On a phone, use **Menu** (top-left) for navigation. Useful on site visits for project
details, contacts and quick questions.

## Good practice
* Keep project deadlines and consultants up to date in the registry — AVA's answers are
  only as good as the records.
* Review every draft before using it. AVA assists; you approve.
